Habit

The daily note comes first.

Before status, before planning, before answering anything about where things stand: read the daily note. It is the index of the day, not a container.

The habit exists because the alternative is guessing from memory, and memory reconstructs rather than recalls. A status doc goes stale within two to four weeks; the day-note does not, because it is written the day it happens.

This one is also a rule for the assistant. When asked what is going on, it reads the note before it answers.
